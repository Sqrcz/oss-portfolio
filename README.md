# Curated Open Source Portfolio

This repository serves as a portfolio of my open source contributions. You can check out the contributions log in the [contributions folder](./contributions) to see my work.

My goal in creating this log is to maintain a detailed and organized record of my work, containing pull requests (PRs), bug reports, and general collaborations. It's a way for me to track my journey and share my contributions with the community.

The content in this repository is generated automatically using a GitHub Action.

## ⚡ Quick Setup

This is a brief overview for getting started. For complete instructions, see the [original repository](https://github.com/adiati98/oss-portfolio).

### Initial Configuration

1. **Delete existing data** to start fresh:
   ```bash
   rm -rf data contributions
   ```

2. **Update the script** in `scripts/update-contributions.js`:
   ```javascript
   const GITHUB_USERNAME = "your-username-here"
   const SINCE_YEAR = 2019  // or your preferred start year
   ```

3. **Enable GitHub Actions** in your forked repository's Actions tab

For detailed setup instructions including local testing, GitHub token configuration, and troubleshooting, please visit the [original repository documentation](https://github.com/adiati98/oss-portfolio#readme).
